# Pull requests

Before resolving or merging a pull request, read its full description (for example, with `gh pr view <number> -R <owner>/<repo> --json body`). Treat any pre-merge instructions in the description as items to verify. Compare each item against the diff and the repository state, make any required changes, and resolve discrepancies before merging. Passing checks and GitHub's mergeable status do not replace this review.
